# 实时示波器真机演示

2026-10-22 当前版本采用 SECTION 中断注册：ESP32-C5 为 31250 Hz，GD32E507 为 10000 Hz。共用 demo 波形默认为 50 Hz、周期 20 ms，可通过参数列表修改幅值和频率。各平台的启动方式和验证记录见下文，旧版记录仅保留为历史资料。

演示平台：ESP32-C5 和 GD32E507。共用同一份 demo，在现有中断中更新真实 RAM 并采样；上位机选择“设备”。ESP32 使用 Wi-Fi，GD32 使用有线以太网。

## 启动

1. 运行 FRAME 的 `build/realtime-demo-profile/start-demo.bat`，使用独立演示配置，不覆盖日常设置。
2. 顶部连接 `COM7`，地址 `2`，E8，波特率 `115200`。
3. 打开“实时示波器”，在主页“数据链路”连接 `192.168.1.17:9001`；IP 变化时使用“搜索设备”。
4. 点击“选择参数”，已预填本次 ESP32 ELF。展开 `g_scope_demo → wave`，将下面四个成员依次加入通道。
5. 数据源保持“设备”，采样率自动查询为 `31250 Hz`（32 μs），不能从上位机修改。显示时长选 `500 ms`，点击“运行”。

| 通道 | 参数 | 下位机生成值 | 建议每格 |
| --- | --- | --- | --- |
| CH1 | `g_scope_demo.wave.sine` | 50 Hz 正弦，-2～2 | 1 |
| CH2 | `g_scope_demo.wave.cosine` | 50 Hz 余弦，-1～1 | 1 |
| CH3 | `g_scope_demo.wave.triangle` | 50 Hz 三角波，-1～1 | 1 |
| CH4 | `g_scope_demo.wave.square` | 50 Hz 方波，0/1，约 50% 占空比 | 0.5 |

`g_scope_demo.sample_count` 每次采样中断递增 1，可用于核对相邻数据点连续性；`g_scope_demo.updates` 为中断中的波形更新计数。展开到普通成员后可右键“指定通道”。

## 参数列表调整波形

连接顶部公共通信链路后，进入“参数读写”，刷新参数列表并搜索 `DEMO_SCOPE`。修改并写入以下参数，正在运行的示波器也会随之变化，无需重新添加通道。

| 参数 | 含义 | 默认值 | 范围 |
| --- | --- | --- | --- |
| `DEMO_SCOPE_AMPLITUDE` | 正弦峰值；余弦、三角波峰值为它的一半 | 2 | 0～20 |
| `DEMO_SCOPE_FREQUENCY` | 四种波形的频率，单位 Hz | 50 | 1～500，整数 |

方波仍为逻辑 0/1，仅随频率变化。幅值为峰值，不是峰峰值；例如幅值 0.8 时正弦为 -0.8～0.8。参数写入经顶部公共 E8 链路完成，数据端口仍只上传。波形频率与固定采样率相互独立，修改不会重配定时器、清空采样缓存或重置波形相位。参数仅保存在 RAM，复位恢复默认值；这些参数只在启用该 demo 的固件中注册。

## 体验操作

- 窗口滚轮缩放时间；在侧边通道表 `/div` 单元格输入或滚轮调整量程。
- 500 ms 窗口显示 25 个周期，采用滚动模式；60 ms 窗口显示 3 个周期。
- 将显示时长设为 50 ms，选择普通触发、CH4、上升沿，拖动右侧 T 到电平 0.5，可观察方波边沿；单次用于捕获后停采。
- 打开 X/Y 游标观察周期和幅值，使用冻结查看缓存。
- 触发源和边沿直接在主页选择。右侧 T 三角游标累计顺时针旋转 90°，尖端向左、竖边贴右边框，T 字保持正向；运行及滚动时保留，拖动时显示电平横线，松开隐藏横线。顶部三角拖动设置触发位置，不再显示电平和百分比输入框。
- 绘制采用保形插值，原始数据、触发和测量不做平滑处理；真实的保持平台仍会保留。

## 实现与边界

代码位于 `code/business/demo/demo_realtime_scope.c`：`REG_INTERRUPT(254, ...)` 按实际采样源频率推进相位并查询只读波形表，`REG_INTERRUPT(255, sample_interrupt)` 随即采样。默认幅值直接复制表值，其他幅值对三个模拟量成员各做一次浮点乘法；中断内不计算三角函数。31250 Hz 采样、50 Hz 波形时每周期 625 点，不再受主任务调度间隔影响。这是固件演示变量，并非外部 ADC 信号或精密信号发生器。硬件 ISR 会有调度延迟，采样率和周期连续性由 CPU 时间戳及递增计数联合检查。

模块不依赖 MCU SDK、不控制功率输出。`DEMO_REALTIME_SCOPE_ENABLE` 默认关闭，ESP32 和 GD32 验证工程显式启用。每个 32 位成员独立更新，不承诺跨成员原子快照。

32 槽位仍保留，超出带宽预算则拒绝启动。上位机始终使用实际烧录对应的 ELF，默认路径为 `platform/esp32c5/build/esp32c5_demo.elf`，MAP 可留空。重新编译或烧录后需要“参数同步”更新地址。

## GD32E507 启动与验证（10 kHz / 50 Hz 波形）

1. 顶部选择“以太网 TCP”，搜索 `GD32E507Z-EVAL`，连接 `169.254.2.7:5000`，地址 2、E8。
2. 实时示波器的数据链路连接同一设备的 `9001` 端口。
3. 选择 `platform/gd32e507/build_realtime/gd32e507_demo.elf`，展开 `g_scope_demo.wave` 添加成员。采样率应答为 `10000 Hz`（100 μs），50 Hz 波形每周期 200 点。
4. 可将窗口设为 60 ms 观察约三个周期，点击“运行”。固件更新后重新“参数同步”。

当前 GD32 使用 SRTOS M、默认 1 ms 时间片，采样缓存/TCP 缓存各 2500 B，新数据每 1 ms 聚合。已修复 SysTick 在 PendSV 活动期间重复请求切换、立即挂起新选中网络任务的问题；示波器核心和服务保持通用。8 通道/10000 Hz 原生链路连续 120 s、1199877 组数据通过，缺包、重复、校验错误、计数跳变及设备溢出均为 0。采样队列峰值 740 B，TCP 环峰值 1221 B，最大聚合间隔 2 ms。最终 ELF SHA256 为 `ABCBC350B4BF6252B3C4860FAE206A4C3C0B3B44CEEE0ABF605F49D29223D770`，已烧录并回读校验；RAM 105872 B/128 KiB（80.77%）。长测固件与最终固件除 ELF 标识外 BIN 完全一致，详见设计 15.12 和 FRAME `build/scope-gd32-pendsv-long/`。代码未提交。

此前仅确认 SRTOS 启用或把时间片缩短到 100 μs 均未解决溢出，记录保留于设计 15.11、FRAME `build/scope-gd32-srtos-2500/` 和 `build/scope-gd32-srtos-fast-2500/`；额外时间片覆盖已撤销。
