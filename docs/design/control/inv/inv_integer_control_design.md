# INV 整型控制设计

## 1. 模块定位

`code/ctrl/inv_i32/` 是单相逆变器的整型控制实现。控制拓扑与浮点 `code/ctrl/inv/` 保持一致，包含：

- APF 正交电压生成和同步坐标系 DQ 变换。
- D/Q 电压 PI 外环。
- 电容电流差分反馈和比例有源阻尼内环。
- 3、5、7 次谐振补偿。
- 输出电压参考前馈、PWM 命令和启停 FSM。

浮点运算只用于配置转换和非 ISR 系数设计。控制 ISR 使用 `int32_t` 状态、`int64_t` 乘加中间值、
32 位整数除法和移位，不使用 64 位整数除法或取模。

## 2. 码域

| 信号 | 物理范围 | 整数范围 | 斜率 |
|---|---:|---:|---:|
| 电容交流电压 | `-400..400 V` | `-2047..2047` | `K_V = 2047 / 400` code/V |
| 母线电压 | `0..500 V` | `0..4095` | `K_BUS = 4095 / 500` code/V |
| 电感和电容电流 | `-100..100 A` | `-8191..8191` | `K_I = 8191 / 100` code/A |
| PWM 电压命令 | 交流电压码 | `AC_CODE * 64000` | `PWM_RELOAD = 64000` |

频率使用 Q16 Hz，峰值电压参考使用 Q16 交流电压码，相位使用一周对应 `2^32` 的 Q32 周期码。
正余弦使用 Q15，最大正幅值为 `32767`。

PLECS 的 `app.c` 在浮点物理域与上述码域之间转换。硬件工程的 ADC 和 PWM 接口需要提供相同码域。

## 3. 电压外环定标

电压 PI 的输入是交流电压码，物理输出是电容电流给定。为了保持 PI 系数量化精度，外环输出使用
`K2 = 1 << 16` 放大的电流码域：

```text
K1 = K2 * K_I / K_V
I_ref_K2 = K1 * Gv(s) * (V_ref_code - V_fb_code)
```

`pi_tustin_i32` 初始化时将 `K1` 乘入浮点 `kp/ki`，运行时输出 `K2 * current_code`。D/Q 反变换完成后，
通过右移 16 位解除 K2，再进入电容电流内环。外环 `±20 A` 限幅也先转换为电流码，再乘 K2。

## 4. 电容电流与内环定标

电容电流由相邻电压采样差分得到：

```text
I_cap_code = (V_cap_code[n] - V_cap_code[n-1])
             * C * Fs * K_I / K_V
```

`C * Fs * K_I / K_V` 保存为 Q16 系数，ISR 使用一次 32×32 位乘法和右移 16 位得到原始电流码。

内环输出直接位于“交流电压码 × PWM reload”域：

```text
K3 = K_inner * PWM_RELOAD * K_V / K_I
V_inner_pwm = K3 * (I_ref_code - I_cap_code - I_harmonic_code)
V_pwm = V_ref_code * PWM_RELOAD + V_inner_pwm
```

PLECS 或硬件 PWM 适配层使用母线反馈将 `V_pwm` 转换为占空比。该边界允许 32 位整数除法，但分子必须先
限制到 32 位；不得执行 64 位整数除法。

## 5. APF、谐振器和相位

- `apf_i32` 使用 Q30 系数。输入和输出均为交流电压码，并保留 Q30 小数残差，避免递归量化形成幅值偏差。
- `resonant_i32` 使用 Q29 系数。输入为交流电压码，前向系数同时包含 `K_I/K_V`，输出直接为电流码。
- 3、5、7 次谐振输出相加后限制为 `±8 A` 对应的电流码。
- `trig_i32` 使用 257 点四分之一波 Q15 表，通过象限重构和线性插值生成正余弦。
- DQ 和反 DQ 使用 Q15 乘加，结果右移 15 位回到输入信号码域。

运行中频率变化时，1 ms 任务根据 Q16 频率快照设计下一组 APF 和谐振系数。任务先完整写入 pending
系数集合，最后发布有效标志；ISR 只在标志有效时一次性切换整组系数。更新阈值为 `0.01 Hz`。

## 6. 64 位中间值边界

`int64_t` 只承担乘法、乘加、比较、饱和和右移。当前码域下的主要上界如下：

| 路径 | 主要中间值上界 |
|---|---:|
| Q15 DQ 电压变换 | `2 * 2047 * 32767 < 1.35e8` |
| 外环反 DQ | `2 * 1.08e8 * 32767 < 7.1e12` |
| APF 单项 | `2047 * 2^30 < 2.2e12` |
| 谐振反馈单项 | `INT32_MAX * 2^30 < 2.31e18` |
| 电容电流差分 | `4094 * cap_gain_q16 < 1.6e9` |
| 相位步长换算 | `freq_q16 * phase_gain_q24 < 2^63` |

APF 和谐振器在右移后检查 `int32_t` 范围。发生饱和时清除小数残差，防止残差继续放大。

## 7. 除法约束

- 允许 `int32_t` 和 `uint32_t` 除法。
- `/` 或 `%` 的任一操作数不得是 `int64_t` 或 `uint64_t`。
- 需要处理 64 位乘积时，先移位或饱和为 32 位，再执行 32 位除法。
- ARM 对象不得引用 `__aeabi_ldivmod`、`__aeabi_uldivmod`、`__divdi3`、`__udivdi3`、
  `__moddi3` 或 `__umoddi3`。

## 8. PLECS 接入

`platform/plecs/inv_i32/` 使用独立构建目录，模型继续加载相对路径 `build/bin/libplecs.dll`。
工程定义 `IS_INV_I32`，只链接 `apf_i32`、`pi_tustin_i32`、`resonant_i32`、`trig_i32` 和
`code/ctrl/inv_i32/`。

该工程保留浮点 INV 模型的输入、输出端口和电路结构，因此两种控制器可以使用相同模型接口分别构建。
