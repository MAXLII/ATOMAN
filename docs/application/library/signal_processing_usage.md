# 信号处理算法库使用方法

## 1. 模块选择

| 需求 | 模块 |
|---|---|
| 周期信号 RMS | `cal_rms` |
| 单频点复数响应 | `dft` |
| 陷波 | `notch` / `notch_i32` |
| 正交信号生成 | `sogi` / `sogi_i32` |
| 相位与频率跟踪 | `pll`、`fll` / `fll_i32` |

## 2. 调用频率

所有离散模块必须按初始化时声明的采样周期稳定调用。若运行在分频任务中，传入的是分频后的真实周期，不是底层 PWM 周期。采样抖动和漏调用会直接表现为相位、带宽或幅值误差。

## 3. 典型处理链

单相同步链可按以下顺序执行：

```text
采样值 → SOGI 正交分量 → PLL/FLL → 相位、频率
```

`sogi_update_frequency()` 可用跟踪得到的角频率更新中心频率，但更新频率应由上层限幅并避免噪声直接调制滤波器系数。

## 4. DFT 使用

调用 `dft_init()` 绑定实时采样指针和启动指针，并给出目标频率与采样周期。启动有效期间，每个样本调用 `dft_cal()`；只有 `output.valid` 有效时才读取实部和虚部。改变目标频率或采样周期后应重新初始化或复位窗口。

## 5. RMS 主从模式

RMS master 使用被测信号判断周期边界并形成计算节拍；slave 复用同一节拍对其他同步通道累积。用于主从同步的标志和样本指针必须持续有效，并在同一采样序列内调用。

## 6. 数值与复位

- 停机、输入源切换或失锁后清除滤波器历史量。
- 整数实现接入前核算输入范围、系数 Q 格式和累加器余量。
- 在线改频时检查模块是否提供系数更新接口；不要直接改内部系数的一部分。
- 观测任务读取输出时应接受其为某个采样时刻的快照。
