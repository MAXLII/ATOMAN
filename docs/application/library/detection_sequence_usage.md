# 检测与时序算法库使用方法

## 1. 模块选择

| 需求 | 模块 |
|---|---|
| 带回差和时间确认的阈值判断 | `hys_cmp` |
| 电网电压、频率资格判断 | `chk_grid` |
| 交流掉电检测 | `ac_loss_det` |
| 继电器合分闸时序 | `rly_on` |
| 通信节点在线超时 | `alive_monitor` |
| 按键长按、短按与冷却 | `key_event` |
| 当前状态与历史状态锁存 | `status_bitmap` |
| 最大功率点跟踪 | `mppt` |
| 线性区间换算 | `linear` |

## 2. 周期换算

检测模块中的 `time`、`time_hys` 或延时计数通常表示连续调用次数。应用应先由物理时间和真实任务周期换算，再传入模块：

```text
确认计数 = 向上取整(确认时间 / 调用周期)
```

任务周期改变时必须同步更新计数参数，否则保护和恢复时间会随调度频率漂移。

## 3. 在线超时

`alive_monitor_init()` 设置在线窗口，初始状态为离线。收到经过验证的有效消息后调用 `alive_monitor_feed()`，周期任务每个时间步调用一次 `alive_monitor_tick()`。剩余计数归零后，`alive_monitor_is_alive()` 返回离线。模块只使用调用次数，不读取平台时钟。

## 4. 按键事件

`key_event` 支持按下期间达到阈值后触发，以及在释放时根据最短、最长按下时间触发。事件由 `key_event_take()` 单次消费；冷却窗口仅在按键释放期间递减，持续按住不会重复触发。GPIO采样和任务注册由业务与项目Interface负责。

## 5. 状态位锁存

`status_bitmap` 同时保存当前有效位和历史锁存位。设置状态会同时写入两者；清除当前状态不会清除历史证据。位索引由初始化时的 `bit_count` 限制，非法索引不会改变对象。

## 6. 回差检测

`hys_cmp_init()` 绑定被测值、动作阈值、释放阈值、确认计数和比较函数。过压判断可使用 `cmp_gt` 动作、`cmp_lt` 释放；欠压判断方向相反。动作与释放阈值必须形成有效回差区间。

## 7. 状态机与硬件回调

`rly_on` 通过 `rly_on()`、`rly_off()` 回调驱动硬件。回调应短小、确定且不可阻塞，模块对象只保存时序状态。硬件反馈、接触器故障和系统联锁仍由应用状态机负责。

## 8. 复位和重新使能

输入源变化、工作模式切换或故障清除时，应调用模块提供的 reset 接口。仅清除最终输出而保留内部计数，会使下一次动作继承旧历史。

MPPT 的 enable、pause、resume 和 disable 含义不同：pause 保留跟踪上下文，disable 用于退出本次跟踪。上下限、起始电压和开路电压应先校验物理关系再写入。

## 9. 输入指针生命周期

检测对象持有调用方输入指针。被测量、触发标志和硬件回调在对象使用期间必须持续有效。若数据来自中断，后台读取多字节值时还需由应用保证快照一致性。
