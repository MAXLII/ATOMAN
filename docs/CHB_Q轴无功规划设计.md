# CHB q 轴无功给定规划设计

## 目标和调用周期

3 级串联 H 桥共用一条网侧电流。在满足各级有功请求、网侧电流额定圆和各桥完整周期调制电压容量时，规划绝对值尽可能小的负 q 轴电流给定。可行时，每级平均承担总基波无功，即 `Q_cell = Q_total / 3`。电网电压生成模块每 12.5 µs 更新；CHB 采样、保护、控制和 PWM 每 100 µs 执行 1 次。无功可行域每 10 个控制拍（1 ms）重算，给定限速每个控制拍执行。12.5 µs 的电网更新不触发额外的控制积分或发波。

## 模块边界

实现在 `code/ctrl/chb/chb_ctrl.c` 内，不增加独立 `.c/.h`。规划器有 `chb_q_plan_input_t`、`chb_q_plan_inter_t` 和 `chb_q_plan_output_t` 3 个结构；只由同一个控制中断调用。`input` 的成员均为指针，指向本拍已限幅的 `id_ref`、实测电网基波 RMS、3 级零和差模有功请求、3 级滤波母线电压及实测电网角频率。调用期间只读这些地址，不保存地址。`inter` 保存目标无功幅值、斜坡幅值、搜索分频计数和零无功可行性；启控时随控制状态复位。`output` 只有 `ref`，单位为 A 峰值，采用负 q 方向。

完整周期谐波电压波形、曲率裕量、调制上限、电感、电阻和电流额定值由同文件控制核心在规划前形成或在 INIT 锁定。规划器通过共用的电压可行域函数读取这组已完成的内部状态；外部调用者无需传入重复的电网谐波或 PWM 数据。

## 数学约束和分配

输入电感也交换无功，所以桥侧总无功一般不等于电网侧无功；平均承担指每级桥侧基波无功相等。

电流额定圆给出 `|iq| ≤ sqrt(max(0, Imax² - id²))`。近空载时，最小电流幅值约束给出 `|iq| ≥ sqrt(max(0, Imin² - id²))`；这是本控制器的轻载均衡下限，不是任意负载都必须吸收无功。各桥有功请求的平均值 `Pavg` 从每桥请求扣除，得到和为 0 的 `ΔPcell`。以电网侧吸收无功为正、d 轴对齐电网电压时，`Qgrid = -0.5 × Vgrid_peak × iq`；各级承担的桥侧基波无功目标为总桥侧基波无功的 `1/3`。在电流对齐坐标中，各桥等无功等价于每桥正交电压为总正交电压的 `1/3`。

每个候选 `|iq|` 都先把总桥电压分为每级平均基值，再加 `2ΔPcell / |I|` 对应的各桥有功投影。完整周期波形（基波与谐波之和）以及节点间曲率上界限制每桥正交电压区间。只有 `总正交电压 / 3` 同时位于 3 级各自的区间内，才认为该候选支持平均承担无功。搜索从轻载下限开始，向电流圆上限分段扫描，并在首个可行边界二分。目标变化以 `600 A/s × 100 µs = 0.06 A/拍` 限速。电流圆上限始终最终夹紧输出 `ref`。

实际电流环电压和静态规划电压可能不同，启动、动态切换或极端不平衡时也可能不存在各级同时满足容量的等无功分配。实时分配先尝试每级相等的正交电压；若当拍任一级不满足完整波形界限，则退回各级允许区间的联合分配，优先保留调制约束和总电压请求。此时不能声称各级仍严格等无功。公共电流环剩余调节电压的正交分量也按 `1/3` 给各级；沿电流的有功分量按母线容量比例分配。最终 PWM 仍对实际作用时刻做各桥电压限幅。

## 观察和验收边界

诊断量 `CHB_IQ_REF_A` 为最终 q 轴电流参考，`CHB_IQ_MIN_A` 为规划目标幅值，`CHB_PF_ZERO_OK` 为最近 1 ms 搜索时的零无功可行性；它们不是电网无功实测值。平衡负载下应检查 `iq_ref`、各桥平均有功/无功、母线、电流 iTHD 和保护状态。不平衡负载下还要检查每桥限幅与等无功退回条件。主机闭环测试只覆盖平均模型；iTHD 和死区影响须用 PLECS 开关模型的原始电感电流波形验证，板级结果另行测量。
