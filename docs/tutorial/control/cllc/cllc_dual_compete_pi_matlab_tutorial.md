## 第 1 章 学习路线与最终目标

### 1.1 最终要解决的问题

当前 CLLC 正向系统的主要规格为：

| 项目 | 数值 |
|---|---:|
| 输出电压范围 | 24～72 V |
| 额定功率 | 6600 W |
| 额定电流 | 150 A |
| 过流限制 | 165 A |
| 输出电容 | 10 mF |
| 控制更新频率 | 100 kHz |
| 变压器变比 | 24:3，即 8:1 |
| 母线参考 | `max(370, 8*Vout_ref + 25)` V |
| 母线动态 | 5 ms 一阶滞后 |
| 调制输出 | 归一化 `u∈[0,1]` |

额定功率和额定电流同时存在，因此输出能力不是全范围恒功率，而是：

\[
P_{out,max}(V_o)=\min(6600,\ 150V_o)
\]

典型稳态点为：

| 输出电压 | 最大正常电流 | 最大正常功率 | 母线参考 |
|---:|---:|---:|---:|
| 24 V | 150 A | 3600 W | 370 V（受到下限限制） |
| 48 V | 137.5 A | 6600 W | 409 V |
| 72 V | 91.67 A | 6600 W | 601 V |

这里必须区分“额定电流”和“保护限流”：

- 150 A 是允许长期工作的额定电流；
- 165 A 是竞争电流环的保护阈值；
- 如果把保护阈值也设置成 150 A，那么 24 V、150 A 工作点没有控制余量，电压环和电流环会在边界竞争。

## 第 2 章 MATLAB 入门：脚本、工作区和运行方式

### 2.1 MATLAB 脚本是什么

`.m` 文件可以是脚本，也可以是函数。当前两份文件主体都是脚本，文件末尾带有局部函数。

脚本的特点是：

- 从上到下依次执行；
- 变量保存在 MATLAB Base Workspace 中；
- 运行结束后可以在 Command Window 查看变量；
- 适合参数设计、数据分析和绘图。

脚本开头常见：

```matlab
clear;
clc;
close all;
```

含义分别是：

- `clear`：清除工作区变量，避免旧变量污染本次计算；
- `clc`：清空命令窗口文字；
- `close all`：关闭旧 Figure，避免新旧图形混在一起。

这三个命令适合独立分析脚本，但不适合被大型程序频繁调用的函数。

### 2.2 分节符 `%%`

MATLAB 使用 `%%` 把脚本分成可单独运行的 Section：

```matlab
%% 用户可调参数
Vin_v = 409;

%% 小信号对象
% 后续计算
```

在 MATLAB Editor 中可以使用“Run Section”只运行当前节。初学调试时很方便，但要注意：当前节依赖的前置变量必须已经存在。

### 2.3 注释

单行注释使用 `%`：

```matlab
current_limit_a = 165; % 单位：A
```

教材式脚本应说明“为什么这样算”，而不仅是复述代码。例如：

```matlab
% 保护阈值取额定电流的 110%，给正常 150 A 工作点留出调节余量。
current_limit_a = 1.10*rated_current_a;
```

1. 当前目录不对，MATLAB 找不到脚本；
2. 修改了设计脚本的参数，却忘记同步时域脚本中的 PI 数值；

## 第 3 章 MATLAB 基本语法

### 3.1 标量和科学计数法

```matlab
Lr_primary_h = 40e-6; % 40 μH
Cr_primary_f = 80e-9; % 80 nF
Cout_f = 10e-3;       % 10 mF
```

MATLAB 默认使用双精度浮点数。`40e-6` 表示：

\[
40\times10^{-6}=0.00004
\]

### 3.2 行向量、列向量和转置

```matlab
x = [1, 2, 3];  % 1×3 行向量
y = x.';        % 3×1 列向量
```

`.'` 是不做复共轭的转置；`'` 对复数还会做共轭。频率响应中存在复数，因此要理解两者区别。

当前脚本统一使用列向量：

```matlab
frequency_hz = logspace(-2, 4, 5001).';
```

### 3.3 冒号、`linspace` 和 `logspace`

等步长时间向量：

```matlab
time_s = (0:sample_time_s:simulation_end_s).';
```

线性频率扫描：

```matlab
switching_frequency_hz = linspace(fr_hz, fmax_hz, 4001).';
```

对数频率扫描：

```matlab
frequency_hz = logspace(-2, log10(0.45*fs_control), 5001).';
```

波特图横轴是对数坐标，所以应优先使用 `logspace`。

### 3.4 数组逐元素运算

MATLAB 中：

- `*`：矩阵乘法；
- `/`：矩阵右除；
- `^`：矩阵幂；
- `.*`：逐元素乘；
- `./`：逐元素除；
- `.^`：逐元素幂。

例如对每个频率计算电容阻抗：

```matlab
Zc = 1./(1j*omega*C);
```

如果写成 `1/(1j*omega*C)`，MATLAB 会尝试矩阵除法，结果可能报错或含义完全不同。

### 3.5 复数

频域电路使用：

```matlab
s = 1j*2*pi*frequency_hz;
ZL = 1j*omega*L;
ZC = 1./(1j*omega*C);
```

复数频率响应的幅值和相位：

```matlab
magnitude_db = 20*log10(abs(response));
phase_deg = rad2deg(unwrap(angle(response)));
```

- `abs`：复数模；
- `angle`：相角，单位 rad；
- `unwrap`：消除相位在 ±π 处的跳变；
- `rad2deg`：弧度转角度。

### 3.6 逻辑索引

逻辑条件会生成只包含 `true/false` 的数组：

```matlab
window = time_s >= 0.1 & time_s < 0.2;
reference_voltage_v(window) = 72;
```

这表示一次性修改 100～200 ms 区间，而不需要逐点循环。

常用逻辑符号：

- `&`：逐元素“且”；
- `|`：逐元素“或”；
- `~`：非；
- `&&`、`||`：标量短路逻辑，常用于 `if`。

### 3.7 条件和循环

```matlab
if voltage_raw <= current_raw
    active_channel = 1;
else
    active_channel = 2;
end
```

```matlab
for sample_index = 1:sample_count - 1
    % 计算第 k 个采样点，并推进到 k+1
end
```

MATLAB 数组从 1 开始编号，不是从 0 开始。

### 3.8 预分配

不要在大循环中不断扩展数组：

```matlab
output_voltage_v = zeros(sample_count, 1);
```

调试时也可使用 `nan`：

```matlab
output_voltage_v = nan(sample_count, 1);
```

如果某个元素忘记赋值，最终会保留 `NaN`，更容易发现错误。

### 3.9 插值

查找某个频率处的增益：


## 第 4 章 CLLC 网络与参数

### 4.1 当前网络

正向 CLLC 参数为：

| 元件 | 参数 |
|---|---:|
| 原边串联谐振电感 | 40 μH |
| 原边串联谐振电容 | 80 nF |
| 原边励磁电感 | 200 μH |
| 副边串联谐振电感 | 0.625 μH |
| 副边串联谐振电容 | 5.12 μF |
| 变比 `Np/Ns` | 8 |

原边串联谐振频率：

\[
f_r=\frac{1}{2\pi\sqrt{L_{r,p}C_{r,p}}}
\]

代入参数：

\[
f_r\approx 88.97\text{ kHz}
\]

最高开关频率定义为：

\[
f_{max}=2f_r\approx177.94\text{ kHz}
\]

MATLAB 实现：

```matlab
fr_hz = 1/(2*pi*sqrt(Lr_primary_h*Cr_primary_f));
fmax_hz = 2*fr_hz;
```

### 4.2 为什么不能直接把开关电路用于 PI 解析设计

完整开关模型包含：

- MOSFET 开关状态；
- 高频谐振电流；
- 变压器和整流换向；
- 死区；
- 同步整流时序；
- 开关纹波；
- 非线性寄生参数。

它适合最终验证，但很难直接得到简洁的 `G(s)`。控制器初始设计通常先进行：

1. FHA 稳态建模；
2. 额定点局部线性化；
3. 低频输出包络建模；
4. PI 频域设计；
5. 再回到开关模型验证。

## 第 5 章 FHA 基波近似建模

### 5.1 FHA 的基本思想

全桥产生方波，但谐振网络通常对基波响应最强。FHA 用方波的基波代替全部高次谐波，把开关网络化为可用复阻抗计算的交流电路。

FHA 适合回答：

- 不同频率的稳态电压增益；
- 额定工作频率；
- 工作点附近的增益斜率；
- 负载变化对增益的影响。

FHA 不适合直接回答：

- 峰值谐振电流；
- 开关瞬间电压和电流；
- ZVS/ZCS 边界的精确位置；
- 死区和器件结电容影响。

### 5.2 直流负载到交流等效负载

全波整流和大输出电容条件下，常用：

\[
R_{ac}=\frac{8}{\pi^2}R_{dc}
\]

48 V、6600 W 时：

\[
R_{dc}=\frac{V_o^2}{P_o}=\frac{48^2}{6600}\approx0.3491\ \Omega
\]

于是：

\[
R_{ac}\approx0.283\ \Omega
\]

MATLAB：

```matlab
load_resistance_ohm = Vout_reference_v^2/output_power_w;
ac_load_resistance_ohm = (8/pi^2)*load_resistance_ohm;
```

### 5.3 各支路复阻抗

令：

\[
\omega=2\pi f
\]

原边串联支路：

\[
Z_{r,p}=j\omega L_{r,p}+\frac{1}{j\omega C_{r,p}}
\]

励磁支路：

\[
Z_m=j\omega L_m
\]

副边串联支路：

\[
Z_{r,s}=j\omega L_{r,s}+\frac{1}{j\omega C_{r,s}}
\]

副边总阻抗：

\[
Z_{s,total}=Z_{r,s}+R_{ac}
\]

折算到原边：

\[
Z'_{s,total}=n^2 Z_{s,total}
\]

其中 `n=Np/Ns=8`。

励磁支路与折算副边并联：

\[
Z_{parallel}=\frac{Z_mZ'_{s,total}}{Z_m+Z'_{s,total}}
\]

### 5.4 电压传递关系

原边串联支路后的分压：

\[
H_p=\frac{Z_{parallel}}{Z_{r,p}+Z_{parallel}}
\]

副边负载分压：

\[
H_s=\frac{R_{ac}}{Z_{r,s}+R_{ac}}
\]

近似直流增益：

\[
M(f)=\left|\frac{H_pH_s}{n}\right|
\]

输出电压：

\[
V_o(f)=V_{bus}M(f)
\]

MATLAB 函数中的核心代码：

```matlab
omega = 2*pi*frequency_hz;
Zr_primary = 1j*omega*Lrp + 1./(1j*omega*Crp);
Zm_primary = 1j*omega*Lmp;
Zr_secondary = 1j*omega*Lrs + 1./(1j*omega*Crs);
Zsecondary_total = Zr_secondary + Rac_ohm;
Zsecondary_referred = n^2*Zsecondary_total;
Zparallel = (Zm_primary.*Zsecondary_referred) ./ ...
    (Zm_primary + Zsecondary_referred);
Hprimary = Zparallel./(Zr_primary + Zparallel);
Hsecondary = Rac_ohm./Zsecondary_total;
dc_gain = abs(Hprimary.*Hsecondary/n);
output_voltage_v = Vin_v*dc_gain;
```

### 5.5 为什么使用向量化计算

`frequency_hz` 是 4001 个频率点组成的列向量。上述代码一次得到整条曲线，不必写 4001 次循环。

这也是 MATLAB 的核心优势之一：先把问题表达成数组和矩阵，再整体计算。

## 第 6 章 PSM/PFM 混合调制与归一化命令

### 6.1 单一控制输出 `u`

控制器只输出一个归一化变量：

\[
0\le u\le1
\]

`u` 的物理含义不是单纯的频率差，而是混合调制命令：

- `0～u_t`：PSM 区；
- `u_t～1`：PFM 区。

### 6.2 PSM 区

在 PSM 区：

- 开关频率固定为 `fmax`；
- 有效占空比从 0 增加到 50%。

映射为：

\[
D=0.5\frac{u}{u_t}
\]

FHA 中用：

\[
V_o(u)\approx V_o(f_{max},D=0.5)\sin(\pi D)
\]

### 6.3 PFM 区

在 PFM 区：

- 有效占空比固定为 50%；
- 频率从 `fmax` 降到 `fr`。

\[
f_s=f_{max}-\frac{u-u_t}{1-u_t}(f_{max}-f_r)
\]

因此在当前正向单调区：

- `u` 增大；
- 频率降低；
- 谐振腔增益提高；
- 输出电压和传输功率提高。

### 6.4 怎样让 PSM 和 PFM 连续

选择：

\[
u_t=\frac{V_o(f_{max})}{V_o(f_r)}
\]

使 PSM 在 50% 占空比的终点与 PFM 在 `fmax` 的起点拥有相同输出。

当前脚本计算得到：

\[
u_t\approx0.24127
\]

这说明 `0～0.24127` 为 PSM，`0.24127～1` 为 PFM。这个边界不是任意写成 0.2，而是由静态电压连续条件求出。

### 6.5 为什么连续映射不等于不需要任何迟滞

静态映射连续，说明不会在边界产生电压命令跳变。但实机仍可能因为：

- 采样噪声；
- 量化；
- 模式判断抖动；
- PSM/PFM 两套时序切换；
- 驱动最小脉宽；

而需要很小的状态迟滞。迟滞用于防止模式高频抖动，不是为了修补静态增益不连续。

## 第 7 章 工作点、非线性与小信号线性化

### 7.1 为什么控制设计需要工作点

CLLC 的 `Vout(u)` 是非线性的。一个固定 PI 不可能在所有 `u` 上都看到相同增益。

频域设计先选择额定工作点：

- 输出 48 V；
- 功率 6600 W；
- 负载 0.3491 Ω；
- 母线 409 V；
- 额定输出电流 137.5 A。

### 7.2 查找额定频率

目标增益：

\[
M^*=\frac{V_o^*}{V_{bus}}
\]

在 `fr～2fr` 单调区中寻找：

\[
M(f_0)=M^*
\]

代码先查找相邻两点误差异号，再线性插值。这样比直接选择“最近的离散点”更精确。

### 7.3 局部斜率

小信号只研究工作点附近的微小变化：

\[
\Delta V_o\approx\left.\frac{dV_o}{du}\right|_{u_0}\Delta u
\]

由于 PFM 区是 `u→fs→Vout`，使用链式法则：

\[
\frac{dV_o}{du}=\frac{dV_o}{df_s}\frac{df_s}{du}
\]

其中：

\[
\frac{df_s}{du}=-\frac{f_{max}-f_r}{1-u_t}
\]

MATLAB 用数值梯度求第一项：

```matlab
voltage_slope_v_per_hz = gradient( ...
    full_psm_output_voltage_v, switching_frequency_hz);
Kvf_v_per_hz = interp1( ...
    switching_frequency_hz, voltage_slope_v_per_hz, ...
    operating_frequency_hz, 'linear');
frequency_gain_hz_per_u = -(fmax_hz-fr_hz)/(1-transition_u);
Ku_v_per_u = Kvf_v_per_hz*frequency_gain_hz_per_u;
```

符号检查：

```matlab
if Ku_v_per_u <= 0
    error('额定点 dVout/du 不是正值，请检查调制方向。');
end
```

如果控制增益符号弄反，负反馈会变成正反馈。

### 7.4 工作点结果

当前额定点约为：

| 量 | 数值 |
|---|---:|
| `u0` | 0.95334 |
| `fs0` | 94.44 kHz |
| `fr` | 88.97 kHz |
| `fmax` | 177.94 kHz |

`u0` 已经接近 1，说明 48 V、409 V 母线额定点靠近谐振频率。设计时要关注高输出点是否还有足够调制裕量。

## 第 8 章 输出包络与小信号被控对象

### 8.1 为什么还要增加动态环节

FHA 曲线给出的是稳态关系，不能说明输出电压需要多长时间变化。

输出端存在 10 mF 电容，控制关注的是开关周期平均后的低频包络。脚本使用一阶近似：

\[
\tau_o=\frac{R_{load}C_o}{2}
\]

48 V、6600 W 时：

\[
\tau_o\approx\frac{0.3491\times0.01}{2}=1.745\text{ ms}
\]

主极点：

\[
f_p=\frac{1}{2\pi\tau_o}\approx91.18\text{ Hz}
\]

### 8.2 电压对象

把静态增益 `Ku=dVout/du`、一阶包络和延时组合：

\[
G_v(s)=\frac{\Delta V_o(s)}{\Delta u(s)}
=\frac{K_u}{1+s\tau_o}e^{-sT_d}
\]

`Td` 近似采样、计算、PWM 更新和一个开关周期带来的总延时。

MATLAB：

```matlab
voltage_plant = Ku_v_per_u ./ ...
    (1 + s*output_time_constant_s).*exp(-s*delay_s);
```

### 8.3 电流对象

电阻负载小信号关系：

\[
\Delta I_o=\frac{\Delta V_o}{R_{load}}
\]

因此：

\[
G_i(s)=\frac{\Delta I_o(s)}{\Delta u(s)}
=\frac{G_v(s)}{R_{load}}
\]

代码：

```matlab
current_plant = voltage_plant/load_resistance_ohm;
```

### 8.4 这是串级双环吗

不是。

串级电压外环、电流内环通常是：

```text
Vref → 电压控制器 → Iref → 电流控制器 → u
```

当前双竞争结构是：

```text
Vref-Vout ─→ 电压 PI ─┐
                      ├→ MIN → u
Ilimit-Iout ─→ 电流 PI ┘
```

两个通道都直接输出同一个 `u`，电流通道是限制器，不是正常串级内环。

### 8.5 模型的适用范围

这个 `Gv` 和 `Gi` 是 48 V 额定点附近的小信号模型。它们不能精确代表：

- 24 V PSM 区；
- 72 V 接近谐振点；
- CR、CC、CP 负载的所有非线性；
- 大幅 24↔72 V 阶跃。

因此频域设计负责给出合理初值，时域非线性平均模型负责做大范围初步验证，最终还要用开关模型确认。

## 第 9 章 PI 控制器的数学基础

### 9.1 PI 的连续域形式

PI 控制器为：

\[
C(s)=K_p+\frac{K_i}{s}
\]

也可写成：

\[
C(s)=K_p\left(1+\frac{\omega_z}{s}\right)
\]

其中：

\[
\omega_z=\frac{K_i}{K_p},\qquad
f_z=\frac{\omega_z}{2\pi}
\]

### 9.2 比例项的作用

比例项：

\[
u_P=K_pe
\]

作用是根据当前误差立即给出控制动作。

`Kp` 增大通常会：

- 提高带宽；
- 加快响应；
- 增强噪声传递；
- 减小对延时和高频未建模动态的容忍度；
- 过大时造成振荡。

### 9.3 积分项的作用

积分项：

\[
u_I=K_i\int e(t)dt
\]

只要稳态误差不为零，积分就继续累积。因此它能消除阶跃给定下的稳态误差。

代价是：

- 引入接近 `-90°` 的相位；
- 容易产生积分饱和；
- 过强时增加超调和低频振荡。

### 9.4 PI 的频率响应

令 `s=jω`：

\[
C(j\omega)=K_p+\frac{K_i}{j\omega}
\]

幅值：

\[
|C(j\omega)|=K_p\sqrt{1+\left(\frac{\omega_z}{\omega}\right)^2}
\]

相位：

\[
\angle C(j\omega)=-\tan^{-1}\left(\frac{\omega_z}{\omega}\right)
\]

低频时积分主导，相位接近 `-90°`；高频时比例主导，相位接近 `0°`。

## 第 10 章 按交越频率解析设计 PI

### 10.1 什么是交越频率

开环：

\[
L(s)=C(s)G(s)
\]

交越频率 `fc` 满足：

\[
|L(j2\pi f_c)|=1
\]

在波特图中就是幅值穿过 `0 dB` 的频率。

交越频率大致决定闭环响应速度，但不能孤立选择。它必须明显低于：

- 控制 Nyquist 频率；
- 开关频率；
- 主要未建模谐振；
- 采样和计算延时开始产生严重相位损失的频率。

当前设计选择：

- 电压通道目标交越频率：350 Hz；
- 电流限制通道目标交越频率：3.5 kHz；
- 控制更新频率：100 kHz。

电流限制通道更快，是为了过流时尽快夺取控制权。

### 10.2 PI 零点位置

两个 PI 零点都放在输出主极点：

\[
f_z=f_p=\frac{1}{2\pi\tau_o}
\]

目的不是数学上完全消除所有动态，而是在带宽附近补偿一阶包络的相位滞后，并得到容易解释的初始设计。

### 10.3 推导 Kp

交越条件：

\[
|C(j\omega_c)G(j\omega_c)|=1
\]

PI 在 `ωc` 的幅值为：

\[
|C(j\omega_c)|
=K_p\sqrt{1+\left(\frac{\omega_z}{\omega_c}\right)^2}
\]

因此：

\[
K_p=
\frac{1}
{|G(j\omega_c)|
\sqrt{1+(\omega_z/\omega_c)^2}}
\]

用频率表示：

\[
K_p=
\frac{1}
{|G(j2\pi f_c)|
\sqrt{1+(f_z/f_c)^2}}
\]

### 10.4 推导 Ki

由：

\[
\omega_z=\frac{K_i}{K_p}
\]

得到：

\[
K_i=\omega_zK_p=2\pi f_zK_p
\]

### 10.5 MATLAB 实现

```matlab
plant_gain = interp1(log10(frequency_hz), abs(plant), ...
    log10(crossover_hz), 'linear');
shape_gain = sqrt(1 + (zero_hz/crossover_hz)^2);
Kp = 1/(plant_gain*shape_gain);
Ki = 2*pi*zero_hz*Kp;
s = 1j*2*pi*frequency_hz;
controller = Kp + Ki./s;
```

这里在 `log10(f)` 坐标中插值，因为波特图的频率轴是对数轴。

### 10.6 当前 PI 参数

电压通道：

\[
K_{p,v}=0.0390561\ \text{u/V}
\]

\[
K_{i,v}=22.3759\ \text{u/(V·s)}
\]

电流限制通道：

\[
K_{p,i}=0.136341\ \text{u/A}
\]

\[
K_{i,i}=78.1121\ \text{u/(A·s)}
\]

这些数值依赖当前母线、变比、负载、工作点和模型。更换硬件参数后不能机械照抄。

## 第 11 章 波特图、稳定裕度和闭环特性

### 11.1 四组需要观察的曲线

设计脚本分别画：

1. 被控对象 `G`；
2. 控制器 `C`；
3. 开环 `L=C·G`；
4. 闭环 `T=L/(1+L)`。

不要只看闭环波特图。稳定裕度来自开环 `L`。

### 11.2 相位裕度

在开环幅值为 `0 dB` 的交越频率处：

\[
PM=180^\circ+\angle L(j\omega_c)
\]

例如交越处相位为 `-120°`：

\[
PM=60^\circ
\]

通常可把 `PM≥45°` 作为初步目标，但具体要求取决于系统、非线性、参数变化和数字延时。

### 11.3 增益裕度

在开环相位到达 `-180°` 时，开环幅值距离 `0 dB` 的余量称为增益裕度。

常用初步目标：

\[
GM\ge6\text{ dB}
\]

### 11.4 为什么低频增益高但相位更低

PI 的积分器使低频增益很高，用于压低稳态误差；同时积分器贡献接近 `-90°` 相位。

这并不自动说明系统有问题。关键是：

- `0 dB` 交越发生在哪里；
- 交越处相位裕度是多少；
- 是否存在多个交越点；
- 高频未建模动态是否让相位继续下降。

低频开环增益高通常是好事，因为它意味着低频扰动抑制和稳态精度好。真正危险的是在相位接近或低于 `-180°` 时，开环幅值仍大于 `0 dB`。

### 11.5 多交越点

高阶电力电子对象可能多次穿越 `0 dB` 或 `-180°`。脚本不只找第一个交点，而是枚举全部交点并返回最差裕度。

这比只读 MATLAB 图上第一处交点更保守。

### 11.6 当前结果

电压通道：

| 指标 | 结果 |
|---|---:|
| 实际交越频率 | 350.94 Hz |
| 相位裕度 | 88.70° |
| 增益裕度 | 36.56 dB |

电流限制通道：

| 指标 | 结果 |
|---|---:|
| 实际交越频率 | 3.510 kHz |
| 相位裕度 | 76.63° |
| 增益裕度 | 16.56 dB |

这些结果在当前简化模型下有较大裕度，但不能直接等同于开关模型和实机的裕度。

## 第 12 章 从连续 PI 到嵌入式离散 PI

### 12.1 连续积分器

连续形式：

\[
\frac{I(s)}{E(s)}=\frac{K_i}{s}
\]

采用前向矩形积分：

\[
i[k]=i[k-1]+K_iT_se[k]
\]

定义每次调用的积分系数：

\[
k_{i,step}=K_iT_s
\]

于是：

\[
i[k]=i[k-1]+k_{i,step}e[k]
\]

### 12.2 为什么 C 模块中的 `ki` 不是连续 Ki

`pi_dual_compete.c` 每次调用直接执行：

```c
i_share += active_ki * active_err;
```

这里没有再乘 `Ts`，所以传入 C 模块的 `ki` 必须是 `Ki*Ts`。

当前控制周期：

\[
T_s=\frac{1}{100000}=10\ \mu s
\]

电压积分步进：

\[
k_{i,step,v}=22.3759\times10^{-5}
\approx0.000223759
\]

电流积分步进：

\[
k_{i,step,i}=78.1121\times10^{-5}
\approx0.000781121
\]

### 12.3 离散 PI 的 Z 域形式

累加器：

\[
i[k]-i[k-1]=k_{i,step}e[k]
\]

Z 变换：

\[
\frac{I(z)}{E(z)}=\frac{k_{i,step}}{1-z^{-1}}
\]

数字 PI：

\[
C(z)=K_p+\frac{k_{i,step}}{1-z^{-1}}
\]

沿单位圆令：

\[
z^{-1}=e^{-j\omega T_s}
\]

得到数字频率响应：

```matlab
z_inverse = exp(-1j*2*pi*frequency_hz*ts);
controller = Kp + ki_step./(1 - z_inverse);
```

这一步使波特图更接近实际 C 实现，而不是只分析理想连续 PI。

### 12.4 常见离散化错误

1. 把连续 `Ki` 直接传给每周期累加器，积分强度大了 `1/Ts` 倍；
2. 已经计算 `ki_step=Ki*Ts`，循环里又乘一次 `Ts`；
3. 控制频率改变后忘记重算 `ki_step`；
4. 仿真使用 Tustin，固件却使用矩形积分，频率响应不一致；
5. 忽略计算和 PWM 更新延时。

## 第 13 章 双竞争 PI 与共积分

### 13.1 两个误差

电压误差：

\[
e_v=V_{ref}-V_o
\]

电流限制误差：

\[
e_i=I_{limit}-I_o
\]

正常运行时 `Io<Ilimit`，所以 `ei>0`。过流时 `ei<0`。

### 13.2 两个候选输出

\[
u_v=K_{p,v}e_v+i_{share}
\]

\[
u_i=K_{p,i}e_i+i_{share}
\]

两路共享同一个积分状态 `i_share`。

### 13.3 为什么正向系统使用 MIN

正向系统中：

- `u` 增大意味着频率降低、传输能力提高；
- 正常时 `ei>0`，电流候选偏大；
- 电压候选较小，因此 MIN 选择电压环；
- 过流时 `ei<0`，电流候选快速下降；
- MIN 改为选择电流环，降低 `u` 和传输功率。

所以：

\[
u=\min(u_v,u_i)
\]

如果系统的控制方向相反，例如 `u` 增大反而降低功率，竞争方向也要重新判断，不能机械使用 MIN。

### 13.4 为什么共享积分

如果两路各自积分：

- 未获胜通道也可能继续积累；
- 切换时两个积分状态不同；
- 输出候选会突然跳变；
- 容易产生模式来回切换和恢复慢。

共享积分的思想是：

- 两个候选拥有同一基线；
- 只有获胜通道更新积分；
- 控制权切换时不切换积分状态；
- 更容易做到无扰切换。

### 13.5 每个控制周期的正确顺序

1. 计算两个误差；
2. 计算两个比例项；
3. 加上旧的共享积分，得到两个候选；
4. 通过 MIN 选获胜通道；
5. 只用获胜通道的误差更新共享积分；
6. 用新的共享积分重建输出；
7. 输出限幅；
8. 进行积分回算；
9. 保存候选值和获胜通道，供观测。

时域脚本刻意复现这个顺序。改变先后顺序会改变离散系统行为。

### 13.6 限幅与抗积分饱和

输出范围：

\[
0\le u\le1
\]

若未限幅输出：

\[
u^*=p_{active}+i_{share}
\]

当输出超过上限：

\[
u=1
\]

反算积分：

\[
i_{share}=1-p_{active}
\]

当输出低于下限：

\[
u=0
\]

\[
i_{share}=0-p_{active}
\]

这样积分器不会在执行器已经饱和时继续向错误方向累积。

### 13.7 稳态竞争检查

48 V 额定点：

\[
e_v=0
\]

\[
e_i=165-137.5=27.5\text{ A}
\]

因此电流候选明显高于电压候选，MIN 选择电压通道。设计脚本会检查这个关系。

## 第 14 章 原理性时域平均模型

### 14.1 时域仿真包含哪些模块

当前时域模型包含：

- 非线性 `u→Vout` FHA 静态曲线；
- PSM/PFM 混合调制；
- 输出电容的一阶包络；
- 动态负载模式；
- 动态母线；
- 数字控制延时；
- 双竞争 PI；
- 输出限幅和积分回算；
- 单次连续事件时间线。

不包含：

- 开关纹波；
- 谐振电流瞬时波形；
- 开关管损耗；
- ZVS/ZCS 细节；
- 死区；
- ADC/PWM 量化；
- 采样噪声；
- 磁性元件饱和；
- 器件容差和温漂。

### 14.2 静态曲线表

脚本先生成：

```matlab
command_grid = linspace(0, 1, 4001).';
```

并在不同负载、不同母线稳态点下计算 `Vout(u)`。

运行时不重复求解全部频率网络，而是：

```matlab
voltage_target_v = interp1( ...
    command_grid, curve.output_voltage_v, command, 'linear');
```

这本质上是一维查表。

### 14.3 多工作点插值

24 V、48 V、72 V 的负载不同。脚本把每条曲线先除以各自母线电压，得到近似无量纲增益，再在相邻工作点之间插值：

```matlab
minimum_gain = Vcurve_min/Vbus_min;
nominal_gain = Vcurve_nom/Vbus_nom;
maximum_gain = Vcurve_max/Vbus_max;
```

最后乘当前动态母线：

\[
V_{target}=V_{bus}\cdot M(u,load)
\]

这利用了 FHA 输出对母线电压近似线性的特点。

### 14.4 显式欧拉法

输出包络微分方程：

\[
\frac{dV_o}{dt}=\frac{V_{target}-V_o}{\tau_o}
\]

显式欧拉离散：

\[
V_o[k+1]=V_o[k]+\frac{T_s}{\tau_o}
\left(V_{target}[k]-V_o[k]\right)
\]

MATLAB：

```matlab
output_voltage_v(k+1) = output_voltage_v(k) + ...
    sample_time_s/output_time_constant_s * ...
    (voltage_target_v - output_voltage_v(k));
```

### 14.5 欧拉法的数值稳定性

一阶系统使用显式欧拉时，应让：

\[
\frac{T_s}{\tau_o}\ll1
\]

当前 `Ts=10 μs`，而输出时间常数通常为毫秒数量级，所以时间尺度相差数百倍，原理性仿真是合理的。

若步长过大，可能出现：

- 数值振荡；
- 过冲被夸大；
- 甚至数值发散。

### 14.6 控制延时线

脚本使用移位数组模拟命令延时：

```matlab
applied_command(k) = command_delay_line(1);
command_delay_line(1:end-1) = command_delay_line(2:end);
command_delay_line(end) = command;
```

这相当于一个离散 FIFO。控制器刚算出的 `command` 不会立即作用于功率级，而是在若干采样后生效。

## 第 15 章 动态母线建模

### 15.1 母线参考

当前策略：

\[
V_{bus,ref}=\max(370,\ 8V_{out,ref}+25)
\]

作用：

- 低压输出时母线不低于 370 V；
- 高压输出时根据变比提高母线；
- 25 V 提供额外调节裕量；
- 72 V 时母线参考为 601 V。

### 15.2 母线一阶滞后

实际母线不能瞬间变化，使用：

\[
\frac{dV_{bus}}{dt}
=\frac{V_{bus,ref}-V_{bus}}{\tau_{bus}}
\]

其中：

\[
\tau_{bus}=5\text{ ms}
\]

离散形式：

\[
V_{bus}[k+1]=V_{bus}[k]+\frac{T_s}{\tau_{bus}}
\left(V_{bus,ref}[k]-V_{bus}[k]\right)
\]

### 15.3 为什么母线动态会影响电压阶跃

CLLC 输出能力近似与母线成正比。大幅升压时，即使 `u` 已经接近 1，母线还没上升到位，输出也不能立刻达到新参考。

大幅降压时：

- `u` 会快速下降；
- 母线也开始下降；
- 两者同时降低传输能力；
- 可能产生明显欠冲。

所以不能只调 PI 而忽略母线协同。工程上还可以研究：

- 输出参考斜坡；
- 母线前馈；
- 升降压不同的母线时间常数；
- 限制 `dVbus_ref/dt`；
- CLLC 与前级母线控制器的带宽分配。

### 15.4 母线图怎样阅读

最终 Figure 第六行单独显示：

- `Vbus ref`：虚线母线参考；
- `Vbus`：实际一阶滞后母线；
- `370 V minimum`：最低母线限制。

当前验证范围：

| 量 | 最小值 | 最大值 |
|---|---:|---:|
| 母线参考 | 370 V | 601 V |
| 实际母线 | 370 V | 约 601 V |

## 第 16 章 CR、CC、额定包络和过载模型

### 16.1 CR 模式

CR 表示恒阻负载：

\[
I_o=\frac{V_o}{R}
\]

电压升高时电流线性增加，功率按平方增加：

\[
P_o=\frac{V_o^2}{R}
\]

FHA 最自然的负载形式就是等效电阻，所以频域设计使用额定电阻工作点。

### 16.2 CC 模式

CC 表示恒流负载：

\[
I_o=I_{CC}
\]

为了 24～72 V 全范围不超过 6600 W，脚本选择：

\[
I_{CC}=\frac{6600}{72}=91.67\text{ A}
\]

于是：

- 24 V 时约 2200 W；
- 48 V 时约 4400 W；
- 72 V 时 6600 W。

如果全范围固定 150 A，72 V 时功率将达到 10.8 kW，违反额定功率限制。

### 16.3 额定包络模式

正常输出能力：

\[
I_o=\min\left(150,\frac{6600}{V_o}\right)
\]

低压区为 150 A 恒流上限，高压区为 6600 W 恒功率上限。

### 16.4 过载模式

48 V、9000 W 的等效电阻：

\[
R_{overload}=\frac{48^2}{9000}=0.256\ \Omega
\]

负载刚接入时理论电流：

\[
I=\frac{48}{0.256}=187.5\text{ A}
\]

超过 165 A 后电流竞争通道获胜，把稳态电流限制在 165 A。输出电压会下降到：

\[
V=165\times0.256=42.24\text{ V}
\]

这正是时域仿真中限流阶段约 42.24 V 的原因，不是电压 PI 失效。

### 17.4 斜坡的 MATLAB 写法

归一化进度：

```matlab
progress = min(max((time_s-t_begin)/(t_end-t_begin), 0), 1);
```

它在：

- 开始前为 0；
- 斜坡中为 0～1；
- 结束后为 1。

任意线性斜坡：

\[
y=y_0+(y_1-y_0)progress
\]

### 17.5 模式切换为什么也使用斜坡

从额定包络切换到 CC 时，负载电流和静态曲线都平滑混合。如果瞬间切换：

- 负载电流可能跳变；
- 输出包络目标可能跳变；
- 无法区分控制问题和负载模型突变。

平滑切换更适合研究控制器本身；真正的负载阶跃则保留在专门的阶跃事件中。

## 第 18 章 阶跃、斜坡和限流指标

### 18.1 上升时间

脚本采用 10%～90% 定义：

\[
t_r=t_{90\%}-t_{10\%}
\]

对于下降阶跃，先用阶跃方向归一化，再寻找 10% 和 90%，所以同一函数可处理上升和下降。

### 18.2 稳定时间

稳定时间不是“第一次进入误差带”的时间，因为响应可能再次离开误差带。

脚本查找最后一次越出误差带的点，其下一点才算稳定。

若观察窗口结束时仍未稳定，返回 `NaN`。这提醒读者：

- 延长仿真窗口；
- 或重新设计控制器；
- 不能把窗口末值强行当成稳定值。

### 18.3 超调和下降欠冲

上升阶跃常说超调，下降阶跃常说欠冲。脚本使用统一的“越过目标方向的峰值”计算。

大幅降压阶跃欠冲明显，原因包括：

- PI 输出快速下降；
- 母线参考同时下降；
- 母线有动态滞后；
- 输出电容和负载发生能量重新平衡；
- 大信号过程远离 48 V 小信号设计点。

### 18.4 阶跃限流与缓变限流

阶跃限流：

\[
I_{limit}:200\rightarrow165\text{ A}
\]

缓变限流在 10 ms 内从 200 A 降到 165 A。

两者最终限流值相同，但暂态不同：

- 阶跃限流响应更快、控制动作更剧烈；
- 缓变限流电流下降更平滑；
- 两者都要检查共享积分是否连续；
- 还要检查恢复到电压环时是否出现二次冲击。

## 第 22 章 常见问题与诊断顺序

### 22.1 输出方向反了

现象：误差为正时输出电压反而下降。

检查顺序：

1. `dVout/du` 是否为正；
2. `u→frequency` 映射符号是否正确；
3. 电压误差是否为 `Vref-Vout`；
4. MIN/MAX 是否选错；
5. PFM 是否工作在预期单调区。

### 22.2 卸载后频率方向错误

当前正向定义下，卸载时：

- 所需功率下降；
- `u` 应下降；
- PFM 频率应上升。

如果频率下降，检查 `frequency_gain_hz_per_u` 的负号。

### 22.3 PI 在 MATLAB 稳定，实机振荡

可能原因：

- 延时估计太小；
- 实际对象有额外极点；
- ADC 滤波引入相位；
- PWM 更新不是每个控制周期立即生效；
- 采样点受到开关纹波干扰；
- 参数随温度和负载变化；
- 固件 `ki` 缩放错误；
- 定点或浮点精度问题。

### 22.4 限流后不能恢复

检查：

1. 额定电流是否与保护限流设成相同；
2. 电流误差符号是否正确；
3. 是否只有获胜通道积分；
4. 输出饱和后是否回算积分；
5. 负载是否要求超过限流能力的稳态电流；
6. 母线和输出参考是否协调。

### 22.5 大幅下降阶跃欠冲

可尝试：

- 给 `Vref` 加下降斜坡；
- 降低电压 PI 带宽；
- 对母线下降设置更慢斜率；
- 加入母线前馈；
- 采用增益调度；
- 单独优化 24 V、48 V、72 V 工作点；
- 检查模型是否把负载变化和给定变化同时施加得过于激烈。

### 22.6 波特图低频相位低

低频积分器导致接近 `-90°` 是正常现象。检查重点不是最低频相位，而是：

- `0 dB` 交越点相位；
- 相位裕度；
- 增益裕度；
- 多交越点；
- 高频相位是否受延时快速拉低。

### 23.2 扫频辨识

G(j\omega)=\frac{\hat V_o(j\omega)}{\hat u(j\omega)}

然后把辨识结果与 FHA 小信号模型比较。若偏差明显，应以辨识对象重新设计 PI。

### A.2 负载换算

\[
R_{dc}=\frac{V_o^2}{P_o}
\]

\[
R_{ac}=\frac{8}{\pi^2}R_{dc}
\]

### A.3 输出包络

\[
\tau_o=\frac{R_{load}C_o}{2}
\]

\[
f_p=\frac{1}{2\pi\tau_o}
\]

### A.4 小信号对象

\[
G_v(s)=\frac{K_u}{1+s\tau_o}e^{-sT_d}
\]

\[
G_i(s)=\frac{G_v(s)}{R_{load}}
\]

### A.5 PI 参数

\[
K_p=\frac{1}{|G(j2\pi f_c)|\sqrt{1+(f_z/f_c)^2}}
\]

\[
K_i=2\pi f_zK_p
\]

### A.6 离散积分系数

\[
k_{i,step}=K_iT_s
\]

### A.7 双竞争

\[
u_v=K_{p,v}(V_{ref}-V_o)+i_{share}
\]

\[
u_i=K_{p,i}(I_{limit}-I_o)+i_{share}
\]

\[
u=\min(u_v,u_i)
\]

### A.8 母线参考

\[
V_{bus,ref}=\max(370,8V_{out,ref}+25)
\]

### A.9 额定输出包络

\[
P_{out,max}=\min(6600,150V_o)
\]

## 结语

这两份脚本展示了一条完整而实用的控制设计路径：

```text
物理电路
→ FHA 稳态模型
→ 工作点和局部线性化
→ 小信号对象
→ PI 频域设计
→ 离散控制器
→ 双竞争共积分
→ 非线性平均时域模型
→ 单次连续事件验证
→ PLECS 开关模型
→ 实机辨识与验证
```

对初学者最重要的不是记住某组 `Kp/Ki`，而是掌握每个参数从哪里来、适用于什么假设、怎样验证，以及模型与真实硬件之间还缺少什么。只有把数学模型、MATLAB 实现、控制逻辑和工程边界连在一起，控制器设计才是可解释、可复现、可继续优化的。
