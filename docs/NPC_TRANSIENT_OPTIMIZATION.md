本轮完成实测 CSV 分析、一拍延迟下的联合 PI 搜索、线性稳定性与非线性负载阶跃比较。**候选参数未通过全部卸载验收。** 初次分析仅比较参数；随后按用户“同步到代码”的要求，将快速响应候选同步至 `npc_cfg_default()` 和 `npc_yd_design_config.m`，供 PLECS 复核。未修改 `.plecs`。

下文“当前”指采集实测波形时的旧参数，候选现已作为代码默认参数。比较脚本显式保留旧参数作为基线，避免默认值变化影响历史对比。

## 实测证据

数据：`platform/plecs/npc/build/bin/npc_trace_20260912_180710_523_17180_1.csv`，仿真时间 386.7028～406.7026 s，5 kHz。该记录覆盖用户截图的不平衡加载和卸载。

- 卸载附近相电压峰值约 855.48 V；控制保持状态 2。
- 卸载附近有 22 个电压限幅采样，无电流给定限幅；随后振荡区间不再限幅。
- 相电压主要附加低频分量约 3.26 Hz。它在 dq 中搬移到约 46.7/53.3 Hz；不能把较弱的 6.46 Hz 分量当成主振荡频率。
- 一秒窗口拟合 beta 低频幅值所得衰减时间常数约 2.88 s。按指数衰减外推至原幅值的 2% 约需 11.3 s，**这是短记录外推，不是已观察到的完整稳定时间**。
- 原始低频幅值会污染电压包络；不能用 Scope 上密集正弦波的视觉厚度直接确定电压环带宽。

复现：MATLAB 中运行 `npc_unload_trace_metrics`。该函数自动读取最新 CSV，按电流 RMS 识别卸载，结果写入 `platform/matlab/npc_sequence/output/trace_unload/`。以后新增记录会改变其输入。

## 尚未通过的卸载验收

1. 理想平均模型未复现实测数秒的卸载尾部；甚至当前参数的某些卸载尖峰已超出保护阈值，与本次实测峰值不一致。
2. 候选改善加载，但理想模型中的不平衡卸载峰值、±2% 恢复反而变差。
3. 补充近似死区误差 `u_applied = u_delayed - (Vdc/2)*(Td/Ts)*Clarke(sign(i_abc))`，取 Td=10 μs。这只是每拍保持电流符号的平均敏感性模型，不含精确换流、零电流二极管状态或实际载波时序。
4. 在该近似下，当前不平衡卸载峰值约 953.21 V、±2% 恢复约 46.4 ms；候选峰值约 944.34 V，但 6 s 窗口内未持续进入 ±2%。平衡重载卸载两组均存在更大的模型尖峰和未收敛结果。

此次按用户要求同步候选用于进一步仿真，不能宣称已经解决 5 s 抖动。下一轮需要把实际 PWM 更新相位、10 μs 死区和近零电流换流纳入同一时域模型，再选择同时改善加载和卸载的方案。保护阈值保持不变。

## 复现与文件

在 MATLAB 将 `platform/matlab/npc_sequence` 加入路径，依次运行：

```matlab
npc_transient_optimize('tune');
npc_transient_optimize('robust');
npc_transient_delay_margin;
npc_transient_optimize('deadtime');
npc_unload_trace_metrics;
```

`output/transient_optimize_tune/` 保存四组 PI 搜索结果、两类负载的轨迹、指标及 `comparison.png`；`output/transient_optimize_robust/` 保存 L/C 敏感性；`output/transient_optimize_deadtime/` 保存死区近似对照。

本轮没有执行 PLECS 或 C testbench。时域模型保护检测不终止积分，便于暴露超限；输出 `complete=1` 仅表示数值计算完成，不代表保护或动态指标通过。
