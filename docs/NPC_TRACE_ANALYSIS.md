# NPC 原始日志分析：电流反馈极性

数据文件：`platform/plecs/npc/build/bin/npc_trace_20260912_162629_138_17180_1.csv`。共 100000 行，采样间隔 200 us，仿真时间 329.6664～349.6662 s，开机后 20 s。频谱及稳态统计使用后 10 s，频率分辨率 0.1 Hz。启动日志确认当前四个 PI、5200 A 限值和 DLL 内部零拍延迟。

## 主要发现

三相电流 Probe 的方向与控制接口约定相反：R9/R11/R10 的端口 1 接电容/负载侧，端口 2 接 NPC 侧；Probe 直接将电阻电流送入 DLL。`app.c` 中三个 `sample_feedback()` 未取反，而 `plecs_port.h` 规定输入电流以逆变器流向输出为正。

PLECS 电阻 Probe 以流入正端的电流为正，正端由被探测元件上的小点表示：[官方 Resistor 文档](https://docs.plexim.com/plecs/latest/components-by-category/resistor/)。应在模型原始 Probe 或平台输入适配中统一这三个通道的极性，避免两边同时取反。

日志中的独立证据：

- A 相 3.3 Hz 电压峰值约 187.872 V，电流约 148.167 A；实测 I/V 约 `-0.06637+j0.78586` S，与当前无源模型的正向结果 `0.04321-j0.79108` S 基本反相。50 Hz 电流有功方向也与预期相反。
- 同时采样的三相 `mean(va*ia+vb*ib+vc*ic)` 约 -30.05 kW。该值受开关同步采样影响，不作为真实平均功率计量，但方向与极性问题相互印证。
- 50 Hz 电压峰值约 563.139 V，叠加 3.3 Hz 成分后原始相电压最大绝对值约 801.3 V。线电压总 RMS 约 729.3 V，高于目标 690 V。
- alpha 控制指令包含同频约 192.644 V 分量；不是仅上位机画图出现的包络。dq 中对应差频约 46.7 Hz。
- 电流给定没有触及 5200 A 限幅，电压调制限幅占稳态采样的 12.746%。上下母线各自约在 662～669 V，远小于交流电压的低频摆幅。
- 三相零序采样电压、电流接近浮点舍入误差，与当前浮空星点接法一致。

## 控制计算核对

使用日志上一拍 PI 积分状态、本拍真实 dq 和母线，独立重算本拍比例、限幅及逆变换。电流给定最大误差约 0.0000655 A，alpha/beta 指令最大误差约 0.0001609 V，未发现本拍 PI 公式、增益使用或指令传递错误。

另从零状态将整个日志送入 double MATLAB 控制器，DSOGI dq 最大误差约 0.0248 V、0.0062 A，但完整积分轨迹与 C 不重合（Iref/指令最大差约 188/348）。此长轨迹回放不能作为整体等价测试通过；这里的 PI 实现核对仅依赖使用已记录状态的逐拍重算，不能混淆两种检查。

## 建议处理

先纠正三相电流采样极性，保持当前 PI、总一拍延迟和保护参数，再抓取同样的启动日志验证。此前 `.m` 的电流方向是逆变器向负载为正，所以 `.m` 稳定不能覆盖现场接反的反馈。不要继续靠加大保护阈值或调 PI 掩盖方向错误。

本次只新增分析脚本 `platform/matlab/npc_sequence/npc_trace_analysis.m` 和本文，未修改 C、DLL、PLECS 或运行参数。结果位于 `output/trace_analysis/`，包含统计 CSV、MAT 和启动图。尚未验证极性修正后的真实仿真。
