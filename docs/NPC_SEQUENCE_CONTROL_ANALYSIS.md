## 最终控制结构

```text
三相输出电压 → Clarke → DSOGI → 正序 dq / 负序 dq
                                  ↓
                         四路电压 PI + ±ωC 解耦
                                  ↓
                         正负序电流参考及联合限幅
                                  ↓
                   +θ / −θ 逆变换并合成 αβ 电流参考
                                  ↓
                谐振内模 + 离散 LC/延迟状态反馈电流控制
                                  ↓
                  三相调制电压裕量限制 + 抗积分饱和
                                  ↓
                    一拍计算延迟 + ZOH 平均 LC 对象
```

独立供电的相位由内部 50 Hz 振荡器产生，DSOGI 中心频率同样取该频率。本模型没有让 PLL 锁定自身输出电压来决定频率；这与并网同步用途不同。PLL 动态、频率扰动和并网稳定性不属于本轮验证范围。

电流内环增加**离散状态反馈阻尼和相位整形的谐振内模**，是针对 5 kHz LC 对象的设计扩展，不是“论文原控制器已直接复现”。仅采用普通比例/谐振级联、忽略 LC 与延迟会给出错误结论。

上述模型参数的读取不代表原 .plecs 功率级已经启用或经过实际仿真。本模型在变压器低压侧建立，**未包含变压器漏感、励磁、折算负载、死区、NPC 中点波动、开关纹波和零序回路**；不能把假设的 10 Ω 直接当成原模型负载。

浮置星形电阻负载采用：

```text
Gabc = diag(g) − g*g'/sum(g),  g = [1/Ra;1/Rb;1/Rc]
Gαβ  = Clarke * Gabc * inverse_Clarke

L*diLαβ/dt = uαβ − vCαβ − R*iLαβ
C*dvCαβ/dt = iLαβ − Gαβ*vCαβ
```

对象通过矩阵指数精确 ZOH 离散化。第 k 拍计算的命令在下一拍才进入对象，不把延迟偷偷设为零。

## 电压外环

在序号 σ=+1/−1 的旋转坐标系中：

```text
eσ = vrefσ − vσ
i_rawσ = Kpv*eσ + integralσ + σ*ω*C*J*vσ
J = [0 -1; 1 0]
```

设置 `Kpv=0.03 A/V`、`Kiv=1 A/(V·s)`。没有负载电流测量前馈，积分器承担稳态负载需求。

联合限幅使用 `norm(i_pos)+norm(i_neg)≤160 A`，它是各相参考峰值的保守约束。限幅同时回算四路积分器；它不是对真实瞬时电感电流的硬件钳位。

## 电流内环与 LC 阻尼

每轴使用 5 状态离散模型：

```text
x_axis = [iL; vC; previous_voltage_command; resonator_state_1; resonator_state_2]
z[k+1] = Ar*z[k] + Br*(i_ref[k]−iL[k])
Ar/Br = ZOH discretization of [0 −ω; ω 0], [1;0]
```

将 LC、控制延迟和谐振内模一起用离散 LQR 设计；加权按电流/电压基值归一化，全部位于 config.m 中。最终输入为：

```text
u_raw = (1+Kv+Kdelay)*v_reference
        + Kref*i_reference
        − Ki_state*iL − Kv*vC − Kdelay*u_previous − Kres*z
```

`v_reference` 是已知独立供电参考，避免把本机电压测量正反馈误用为电网电压前馈。当前计算出的系数：

- `Kref = 0.6 V/A`
- `[Ki_state,Kv,Kdelay] = [-0.466923514,-0.135652049,-0.660459323]`
- `Kres = [-237.082099,-53.7587751]`

这些是离散状态反馈系数，不能按连续域“电阻必须为正”的直觉翻转符号。其正确性由完整离散闭环验证，而不是单个系数符号判断。

电压命令限幅采用三相 span：`max(uabc)−min(uabc)≤0.95*Vdc`，αβ 等比例缩放，随后回算谐振状态。该平均模型限制调制可实现范围，不生成开关脉冲。

## 稳定性分析方法

完整模型包含 26 个状态：4 个 LC 状态、12 个双 SOGI 历史量、4 个电压积分状态、4 个电流谐振状态、2 个延迟命令。

正负序变换使闭环为周期时变系统。每个 50 Hz 周期有 100 个控制点，脚本在无限幅条件下精确构造每拍状态矩阵 Ak，计算：

```text
Φ = A99*A98*...*A0
μ = eig(Φ)
rho = max(abs(μ))
```

`rho<1` 是本周期线性模型的局部渐近稳定判据。脚本另给出名义平衡负载下、LC 状态反馈之后的谐振电流返回比 Bode、全部裕度和内环状态空间极点。**电压外环与 DSOGI 的整体稳定性以完整 Floquet 结果为准**，没有用粗略一阶序分离模型的外环相位裕度代替。

当前运行结果：

| 检查 | 结果 |
|---|---:|
| 名义完整周期谱半径 | 0.848020 |
| 不平衡负载 [5,10,20] Ω 谱半径 | 0.883408 |
| L/C 各 ±20%、9 个组合的最坏谱半径 | 0.85919 |
| 名义内环谐振返回比相位裕度 | 86.52° |
| 上述返回比增益交越频率 | 65.89 Hz |

这里的 65.89 Hz 是谐振返回比的一个交越点，不是 dq 外环带宽或整个电流跟踪系统的唯一带宽。所有交越信息保存在 `analysis.mat` 的 `inner_allmargin` 中。

元件偏差扫描保持控制器不变、改变实际对象，但负载固定为平衡 10 Ω。负载不平衡测试使用名义 L/C。没有声称验证了“元件偏差与任意负载同时变化”的全部组合。

对照组关闭离散状态阻尼、使用相同普通级联参数时存在不稳定乘子。这仅说明该对照组不适用，不能据此证明所有普通 PI/PR 参数都不可能稳定。

## 时域结果与验收边界

每例 2.4 s，0.6 s 施加负载变化；严重过载在 0.9 s 撤除。稳态值取最后 0.2 s，VUF 为 DSOGI 负序/正序幅值比。

| 工况 | AB 线电压 RMS / V | 稳态 VUF | 实际最大相电流 / A |
|---|---:|---:|---:|
| 启动 | 690.114 | 0.0165% | 62.81 |
| 平衡负载阶跃 | 689.944 | 0.0164% | 150.16 |
| 不平衡负载 | 690.111 | 0.0165% | 83.57 |
| 1 Ω 严重过载撤除后的恢复 | 690.141 | 0.0166% | 967.72 |
| 关闭负序电压控制的对照组 | 552.626 | 32.92% | 77.78 |

**严重过载时实际电流远超 160 A，虽然撤除负载后恢复了电压。** 该工况验证的是饱和及恢复，不是过流保护通过。报告单独输出 `actual_current_within_reference_limit=false`，不能把“参考限幅存在”解释为“实际电流受限”。移植前仍需独立快速过流保护及过载降压/关断策略。

正常三种工况断言电压误差 <2%、实际峰值电流不超过假设上限；不平衡工况断言 VUF<0.5%，并优于关闭负序控制。过载只断言有限状态和恢复电压。线性稳定性、非线性恢复和硬件安全边界分别报告，不互相替代。

## 文件与运行

目录：`platform/matlab/npc_sequence/`。

- `npc_sequence_analysis.m`：主入口，运行稳定性、5 个时域场景、断言并导出图表。
- `npc_sequence_config.m`：对象、采样、额定值、增益、LQR 权重。
- `npc_sequence_plant.m`：浮置星形 LC 平均对象和精确 ZOH。
- `npc_sequence_step.m`：完整单拍 DSOGI/双序控制、限幅和延迟。
- `npc_sequence_stability.m`：完整 Floquet、参数扫描及内环返回比。
- `npc_sequence_simulate.m`：时域扰动与数据记录。
- `npc_sequence_tune.m`：可选的小信号增益筛选，只输出候选表，不覆盖已验证配置。谱半径最小不等于非线性工况最优。

MATLAB 中运行：

```matlab
cd('D:/OneDrive/LWX/GD32/base/platform/matlab/npc_sequence');
report = npc_sequence_analysis();
```

输出位于 `output/`：

- `stability.png`、5 个时域 PNG。
- `summary.csv`、`robustness.csv`、各工况逐拍 CSV。
- `analysis.mat`，含配置、乘子、状态矩阵、裕度、波形和汇总。
- 可选 `tuning_candidates.csv`。

本轮结果是一个带有明确对象假设的可执行控制分析方案，不是实际 NPC＋变压器系统的最终整定，也没有改写已有 DSOGI、PLL 或 PWM 的 C 实现。
