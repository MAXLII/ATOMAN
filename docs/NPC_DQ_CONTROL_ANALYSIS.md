# NPC 正负序 dq 双闭环 MATLAB 实现

## 入口与结构

本版本对应 `docs/images/npc_sequence_dq_control.svg`：正负序各有 d/q 电压外环和 d/q 电流内环，共 8 个 PI。两套电压指令反 Park 变换后相加，输出 αβ 电压指令。电压和电感电流各经过一套 DSOGI 序分离。

MATLAB 中进入 `platform/matlab/npc_sequence`，运行：

```matlab
report = npc_dq_analysis();
```

实测环境为 MATLAB R2022b。这个入口只使用 MATLAB 基础矩阵计算和绘图；模型包含精确 ZOH 平均 LC 对象和一拍计算延迟。不调用旧版 PR / 状态反馈控制入口 `npc_sequence_analysis`。

## 控制器接口

```matlab
p = npc_dq_config();
s = zeros(32, 1);             % 初始化；复位时清零全部控制器状态
input.v_abc = [va; vb; vc];   % 输出相电压，V
input.i_l_abc = [ia; ib; ic]; % 电感电流，桥臂流向输出端为正，A
input.theta = theta;         % 与采样同一时刻的外部相位，rad
input.vd_pos_ref = amplitude;% 正序 d 轴电压给定，相电压峰值，V
[s, output] = npc_dq_control(s, input, p, true);
% output.u_alpha / output.u_beta 送后级 SVPWM
```

三相为三线制，Clarke 采用幅值不变形式；零序不在本控制范围内。输入应为有限实数，控制器由调用者严格每 200 μs 调用一次。`limited=true` 是实际时域路径；`false` 仅供无饱和小信号分析。

正序变换使用 `Park(theta)`，负序使用 `Park(-theta)`。参考向量顺序为 `[d+;q+;d-;q-]`，电压给定为 `[amplitude;0;0;0]`。负序电流给定由电压外环计算，不固定为零。

状态包括电压 DSOGI 12 项、电流 DSOGI 12 项、外环积分 4 项、内环积分 4 项。输出还提供 `v_dq`、`i_l_dq`、`i_l_dq_ref`、限幅后的 `u_dq` 以及两个限幅标志，便于观测。`npc_dq_step` 是另一个仿真封装，额外包含物理对象和延迟状态，控制器本身不访问这些状态。

相位由外部提供；测试平台提供 50 Hz 相位及非零初相位。DSOGI 中心频率固定为配置的 50 Hz，没有内部 PLL，也没有从相位差分估计频率。本轮没有验证频率漂移或 PLL 动态。

## PI 与限幅

对每个序别和轴，采用先输出、后更新积分的离散实现：

```text
i_raw = Kpv * (v_ref - v_feedback) + integral_v
u_raw = Kpi * (i_ref - i_feedback) + integral_i
integral_next = integral + Ts * (Ki * error + Kaw * saturation_error)
```

正负序使用相同增益：`Kpv=0.2609166 A/V`、`Kiv=17.33260 A/(V·s)`、`Kpi=0.4003825 V/A`、`Kii=398.8813 V/(A·s)`。两层抗饱和回算速率均为 `10 /s`。这些是当前平均对象下的分析候选值，不是硬件参数承诺。

电流给定满足 `norm(i_dq_pos_ref)+norm(i_dq_neg_ref)<=160 A`；超限时四轴统一缩放。电压合成后按三相最大最小值之差限制在 `0.95*Vdc` 内，同一个缩放量回分到正负序积分器进行回算。控制律仅含 PI，没有 PR、状态反馈或额外前馈解耦支路。

可选 `npc_dq_tune` 使用多起点数值搜索，最小化三种负载下完整系统的最大周期谱半径，且限制外环比例增益不超过 `Ipeak/Vpeak`。它不覆盖配置文件；搜索结果必须另行通过时域与鲁棒性检查，不能直接视为可用参数。

## 对象与验证

沿用当前 NPC 分析的参数：L=80 μH、C=200 μF、串联电阻 1 mΩ、母线 1331 V、目标线电压 690 V RMS。负载为假设的浮动星形电阻：名义每相 10 Ω，平衡阶跃至每相 5 Ω，不平衡阶跃至 `[5,10,20] Ω`。不包含变压器、开关纹波和死区。

小信号模型有 38 个状态，逐采样调用与时域相同的控制器构造状态矩阵，求一周期的 Floquet 乘子；谱半径小于 1 表示该无饱和周期模型局部稳定，不能替代全局饱和稳定性证明。名义谱半径约 0.248754，不平衡负载约 0.347491；固定控制器、L/C 各 ±20% 的 9 点扫描最差约 0.263456。

`npc_dq_test` 验证正负序及相位符号、实际状态更新与线性矩阵一致性、正负序联合限幅、抗饱和回算。主入口验证启动、负载阶跃、不平衡负载、幅值降至 80%、过载恢复，保存 CSV、PNG、MAT 至 `output/dq/`。同时用实际三相电压的基波相量独立计算负序占比，不只依赖 DSOGI 反馈。

当前正常工况线电压约 690.114 V，80% 给定时约 552.091 V；DSOGI 反馈负序占比约 0.0165%，包含离散滤波误差。正常工况实际电流峰值最高约 146.273 A。

过载测试将每相负载临时降至 1 Ω，恢复后电压调节通过，但实际电流峰值约 **845.624 A**。160 A 是电流给定限制，不是实际电流硬限制；过载保护尚不在当前实现范围，不能用该结果宣称通过硬件保护验证。

本次仅实现 MATLAB 控制与验证模型，未修改 `.plecs`、DLL 或嵌入式控制代码。
